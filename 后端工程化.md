## 一句话定义

**Agent + FastAPI 后端工程化** = 用 FastAPI 作为接入与编排层，把 **Agent Runtime、工具调用、RAG、记忆、模型网关、策略、评估、可观测** 做成可复用服务，并具备多租户、权限、审计、流式、长任务、人机协同和生产部署能力。

---

```text
渠道层：Web / 移动端 / IM / API / 工单 / 语音
        ↓
FastAPI 接入层：路由 / 认证 / 限流 / 多租户 / SSE / WebSocket
        ↓
Agent 平台层：

        ↓
数据与集成层：
  PostgreSQL | Redis | 向量库 | 对象存储 | 消息队列 | 企业系统连接器
        ↓
基础设施：Docker | K8s | CI/CD | Prometheus | OpenTelemetry | Sentry
```

## 四、FastAPI 分层：Router → Service → Runtime → Repository

**Router 只做参数校验、鉴权、调用 Service、返回响应。**

```python
# app/modules/agent/router.py
from fastapi import APIRouter, Depends
from .schemas import ChatRequest, ChatResponse
from .service import AgentService
from app.core.dependencies import get_agent_service, get_current_user

router = APIRouter(prefix="/agent", tags=["agent"])

@router.post("/chat", response_model=ChatResponse)
async def chat(
    payload: ChatRequest,
    service: AgentService = Depends(get_agent_service),
    user = Depends(get_current_user),
):
    return await service.chat(payload, user)
```

**Service 编排业务，调用 Agent Runtime。**

```python
# app/modules/agent/service.py
class AgentService:
    def __init__(self, runtime: AgentRuntime, memory, rag, audit):
        self.runtime = runtime
        self.memory = memory
        self.rag = rag
        self.audit = audit

    async def chat(self, payload: ChatRequest, user) -> ChatResponse:
        context = await self.memory.load(payload.session_id, user.id)
        docs = await self.rag.retrieve(payload.query, user)
        result = await self.runtime.run(
            query=payload.query,
            context=context,
            docs=docs,
            user=user,
        )
        await self.audit.log(user.id, "agent.chat", result.trace_id)
        return ChatResponse(answer=result.answer, trace_id=result.trace_id)
```

## 五、Agent Runtime 核心设计

Runtime 是 Agent 的“操作系统”，不要写在 Router 或 Service 里。

**典型状态机：**

```text
IDLE → PLANNING → ACTING → OBSERVING → REFLECTING → DONE
                   ↓
              WAITING_APPROVAL
                   ↓
                FAILED
```

**核心接口：**

```python
# app/modules/agent/runtime.py
class AgentRuntime:
    def __init__(self, planner, tool_executor, llm, policy, memory):
        self.planner = planner
        self.tool_executor = tool_executor
        self.llm = llm
        self.policy = policy
        self.memory = memory

    async def run(self, query, context, docs, user) -> AgentResult:
        state = AgentState(query=query, user=user, context=context, docs=docs)
        while not state.done:
            action = await self.planner.next(state)
            if action.type == "tool":
                await self.policy.check(action, user)
                result = await self.tool_executor.execute(action, user)
                state.observe(result)
            elif action.type == "answer":
                state.finish(await self.llm.generate(state))
            elif action.type == "approval":
                state.wait_approval(action)
        return state.to_result()
```

**要点：**
- 状态可持久化，支持检查点、恢复、重试。
- 每一步都有 Trace ID。
- 工具调用必须经过策略引擎。
- 敏感动作进入审批流。

## 六、工具系统：注册、Schema、鉴权、沙箱、幂等

**工具注册中心：**

```python
# app/modules/agent/tools/registry.py
class ToolRegistry:
    def __init__(self):
        self._tools = {}

    def register(self, name, schema, handler, scopes=None, idempotent=True):
        self._tools[name] = {
            "schema": schema,
            "handler": handler,
            "scopes": scopes or [],
            "idempotent": idempotent,
        }

    def get(self, name):
        return self._tools[name]

    def list_for_user(self, user):
        return [t for t in self._tools.values() if self._allowed(t, user)]
```

**工具执行器：**

```python
class ToolExecutor:
    async def execute(self, action, user):
        tool = registry.get(action.name)
        if not self._allowed(tool, user):
            raise PermissionError("tool not allowed")
        if tool["idempotent"] and action.idempotency_key:
            cached = await cache.get(action.idempotency_key)
            if cached:
                return cached
        result = await tool["handler"](**action.args)
        await audit.log(user.id, "tool.call", action.name, result)
        return result
```

**企业级必备：**
- 每个工具有 JSON Schema。
- 权限 Scope 控制。
- 网络隔离、沙箱执行。
- 幂等键防重复执行。
- 超时、重试、熔断。
- 工具调用全审计。

## 七、RAG 与记忆

**RAG 服务：**

```python
class RagService:
    async def retrieve(self, query, user, top_k=5):
        embedding = await self.embedder.embed(query)
        docs = await self.vector_store.search(
            embedding,
            top_k=top_k,
            filter={"tenant_id": user.tenant_id},
        )
        docs = await self.reranker.rerank(query, docs)
        return docs
```

**要点：**
- 分块、嵌入、检索、重排、引用。
- 权限过滤：只能检索用户可见知识。

- 缓存热点检索结果。
- 知识库更新走异步任务。

- 摘要压缩，避免 Token 爆炸。
- 记忆写入需策略控制。

## 八、模型网关

```python
class ModelGateway:
    async def generate(self, messages, model=None, tenant=None):
        model = self.router.select(model, tenant)
        provider = self.providers[model.provider]
        try:
            return await provider.generate(messages, model)
        except Exception:
            fallback = self.router.fallback(model)
            return await self.providers[fallback.provider].generate(messages, fallback)
```

**要点：**
- 多模型路由、Fallback。
- 配额、限流、预算。
- Token 统计、成本归因。
- 结果缓存。
- 小模型优先，复杂任务再上大模型。
- 支持公有云 + 私有化模型。

## 九、流式输出：SSE 事件协议

Agent 的流式不只是 Token，还包括引用溯源、阶段、收尾状态。

**统一事件协议（唯一权威源：《API接口与SSE事件协议规范.md》§5，此处仅为摘要）：**

事件名固定 `source / phase(retrieving[/inspecting]/generating/validating) / message / done`（任务类另有 `progress/complete/error`）；`done` 载荷必含 `references + guard + faithfulness + trace_id`。**与旧设计差异：工具调用不是独立事件类型**（经 `done.tool_calls[]` 透出）、**审批不是事件**（走 `WAITING_APPROVAL` 状态机 + `/approvals` 接口）、错误不单独占事件（信封 `fail` + 数字错误码号段）。旧 `text/tool_call/tool_result/approval/error/done` 联合作废。

**FastAPI SSE（`event:` + `data:` 两行一帧，帧间空行）：**

```python
from fastapi.responses import StreamingResponse

@router.post("/chat/stream")
async def chat_stream(payload: ChatRequest, service: AgentService = Depends()):
    async def event_generator():
        async for name, event in service.stream_chat(payload):
            yield f"event: {name}\ndata: {event.model_dump_json()}\n\n"
    return StreamingResponse(event_generator(), media_type="text/event-stream")
```

**要点：**
- 断线重连 + 幂等键 `client_msg_id`（同（会话，键）重调只落一行）。
- 前端按 `event:` 名分发渲染，`data:` 允许多行、按换行拼接后解析。
- 审批走 `WAITING_APPROVAL` 状态机 + `/approvals` 接口等用户确认，不占事件。
- 长任务（>30s）返回 `{task_id}` 转任务轮询 / WebSocket，不阻塞 SSE。

## 十一、人机协同与审批

- 敏感工具调用进入 `WAITING_APPROVAL`。
- 审批接口：`POST /approvals/{id}/approve`。
- 审批记录审计。
- 支持修改参数后重试。
- 异常转人工。
- 前端展示审批卡片。

```python
class ApprovalService:
    async def request(self, action, user, reason):
        approval = await self.repo.create(action, user, reason)
        await notify(user, approval)
        return approval

    async def approve(self, approval_id, user, modified_args=None):
        approval = await self.repo.get(approval_id)
        await self.policy.ensure_can_approve(user, approval)
        return await self.runtime.resume(approval, modified_args)
```

```python
class EvaluationService:
    async def run(self, dataset, agent_version):
        results = []
        for case in dataset:
            output = await self.runtime.run(case.input)
            score = await self.judge.score(case, output)
            results.append(score)
        return aggregate(results)
```
