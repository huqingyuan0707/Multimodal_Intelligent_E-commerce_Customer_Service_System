# 牛仔洗护与保养

## 政策口径
1. 新牛仔首次下水会掉浮色，属正常；深色牛仔前三次单独洗涤。
2. 日常少洗：局部污渍点洗、通风晾晒即可；机洗翻面、拉链扣好、30℃ 轻柔档。
3. 原色/养牛款：6 个月内尽量不洗以养落色，洗后落色变化属玩法不属质量问题，下单前须明示。
4. 弹力牛仔（含氨纶）忌高温烘干，高温会杀死弹力导致松垮。

## 客服话术要点
- 掉色投诉先问洗涤次数与方式，对照本篇解释浮色与固色区别。
- 养牛款售前必须主动说明“会落色、越穿越有个人痕迹”，避免预期差。

## 转人工边界
- 洗一次即大面积发白、磨破（疑似水洗工艺缺陷），转人工要照片走质检。
