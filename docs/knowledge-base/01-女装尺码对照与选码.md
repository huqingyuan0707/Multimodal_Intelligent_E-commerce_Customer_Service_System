# 女装尺码对照与选码

## 政策口径
1. 女装常规尺码：XS（155/76A）、S（160/80A）、M（165/84A）、L（170/88A）、XL（175/92A），括号内为身高/胸围参考。
2. 不同版型同尺码实测围度差可达 2-4cm，下单前以商品详情页“尺码表”实测数据为准，本篇为通用基线。
3. 顾客在两码之间时：偏修身版型建议选大一码，常规与宽松版型建议选小一码。
4. 给范围不给绝对值；信息不足时必须追问身高、体重、平时穿码三项中缺失的一项。

## 客服话术要点
- 先问三要素：身高、体重、平时穿什么码，再给建议，例如“M-L 均可，常规版建议 M”。
- 主动提醒看商品详情页实测尺码表，话术：“亲，上面是通用对照，具体这件还请以详情页尺码表为准哦”。

## 转人工边界
- 顾客提供三围等敏感信息后仍无法确定，或坚持要“保证合身”承诺时，转人工并注明已收集的数据。
