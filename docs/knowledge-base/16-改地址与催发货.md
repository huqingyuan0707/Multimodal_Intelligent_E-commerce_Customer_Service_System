# 改地址与催发货

## 政策口径
1. 未发货订单可改地址：客服在打单前直接改，改后复述新地址请顾客确认，全程留痕。
2. 已发货仅可拦截改派（部分快递支持），拦截费 3-5 元由责任方承担，改派时效 +1-2 天。
3. 催发货：现货 24 小时未发可催仓，48 小时未发自动升级；预售按约定时间，不提前催仓。
4. 地址涉 PII：展示脱敏（如 138****1234），完整地址不截图外发，通话复述后删除草稿。

## 客服话术要点
- 改地址三步：复述旧地址 → 确认新地址逐字 → 告知“已改好，发出前都有效”。
- 催发货给回执：“已帮您加急到仓库，今晚 10 点前我再跟您同步一次”。

## 转人工边界
- 跨境/顺丰保价件改地址、拦截失败，转人工对接快递网点。
