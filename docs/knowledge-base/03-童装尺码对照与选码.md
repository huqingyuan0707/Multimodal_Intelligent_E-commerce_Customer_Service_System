# 童装尺码对照与选码

## 政策口径
1. 童装按身高选码为主：90（2-3 岁/身高 90cm）、100（3-4 岁）、110（4-5 岁）、120（6-7 岁）、130（8-9 岁）、140（10-11 岁）、150（12 岁+）。
2. 年龄仅参考，身高体重为准；偏胖体型建议大一码，偏瘦体型可小一码。
3. 婴幼儿（90 码以下）注意裆部按扣与领口弹性说明，以详情页为准。
4. 童装不承诺“穿几年”，只给当前合身建议。

## 客服话术要点
- 第一句就问孩子身高和体重（年龄辅助），再给码。
- 提醒：“小朋友长得快，介于两码之间建议选大一码，袖口裤脚可卷边穿”。

## 转人工边界
- 特殊体型、医疗/过敏面料咨询，转人工并记录需求。
