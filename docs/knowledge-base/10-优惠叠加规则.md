# 优惠叠加规则

## 政策口径
1. 叠加顺序：商品折扣 → 店铺满减 → 平台满减 → 优惠券 → 积分抵扣 → 运费险/包邮，系统按最优组合自动计算。
2. 同一订单优惠券限用 1 张（商品券与店铺券取高者，不可同享）；满减门槛按折扣后实付金额计算。
3. 预售尾款：定金膨胀不与店铺券同享，尾款可用平台券，具体以结算页为准。
4. 大促期间规则以会场公告为准，本店客服话术随知识版本切换，不口头承诺公告外优惠。

## 客服话术要点
- 被问“还能再便宜吗”，先帮算当前最优组合：“亲，这单已叠满减+券，到手 XX 元是当前最低了”。
- 不确定的组合让顾客截图结算页，客服按图核对，不凭记忆报价。

## 转人工边界
- 结算价与承诺价差超过 5 元或顾客要求补差价，转人工核对后按改价/补券流程处理。
