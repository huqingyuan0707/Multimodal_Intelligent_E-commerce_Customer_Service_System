# 优惠券领取使用与核销

## 政策口径
1. 领取：店铺首页/商品页/直播间领取，限领张数与有效期以券面为准；发券总量有限，领完即止（超预算返回券已领完）。
2. 使用：限指定店铺/商品、满足门槛，单订单限 1 张；券后价为实付依据，退款按券后金额退，券本身过期不补。
3. 核销：下单支付成功即核销；未支付取消订单券自动退回（15 分钟内到账），超时未退回联系客服。
4. 客服安抚券：按话术模板发放，单张面额超阈值需进审批，发放记录全链路可查。

## 客服话术要点
- “券用不了”先问三件事：过期了吗、门槛够吗、商品在可用范围吗，九成可当场定位。
- 明确告知退款退的是券后金额，避免“退全款”误解。

## 转人工边界
- 券未到账、核销后订单异常（钱扣了单没生成），转人工核对发券与订单流水。
