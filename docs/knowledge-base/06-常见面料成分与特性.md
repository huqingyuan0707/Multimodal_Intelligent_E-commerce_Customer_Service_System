# 常见面料成分与特性

## 政策口径
1. 纯棉：吸湿透气、亲肤，缺点是易皱、深色易掉色、无弹款有缩率（约 3-5%）。
2. 涤纶（聚酯纤维）：抗皱耐磨、快干，缺点是透气性弱、易起静电；常与棉混纺取长补短。
3. 氨纶（莱卡）：提供弹力，含量 3-8% 即有明显弹感，贴身款必备。
4. 亚麻/苎麻：透气凉爽、天然褶皱感是风格而非瑕疵，洗后会变软。
5. 羊毛/羊绒：保暖、缩绒风险高，必须干洗或轻柔手洗；起球属正常摩擦现象，1-2 级可接受。
6. 莫代尔/粘纤：悬垂顺滑，湿态强度低，洗涤忌用力拧绞。

## 客服话术要点
- 被问“这面料好不好”时，按场景答：通勤选抗皱（涤棉混纺）、贴身选纯棉莫代尔、冬天选羊毛，按需推荐不贬低任何成分。
- 主动告知缩率与掉色属于成分特性，非质量问题，但须在发货前说明。

## 转人工边界
- 顾客质疑成分与吊牌不符（要求检测报告），转人工并走质检流程。
