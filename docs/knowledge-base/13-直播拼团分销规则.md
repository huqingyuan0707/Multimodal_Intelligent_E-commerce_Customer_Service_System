# 直播拼团分销规则

## 政策口径
1. 直播价：仅直播间下单有效，主播口播价与系统价不一致时以结算页为准，差价可申请补发券。
2. 拼团：成团才发货，24 小时未成团自动退款（原路退回 1-3 天）；拼团订单不与店铺券同享。
3. 分销员：口令/短链归因，结算周期 T+7，刷单/自买自卖取消资格并冻结佣金，可申诉一次。
4. 好评返现：仅限“晒图+追评”合规话术，禁“不给好评不发货”等诱导胁迫，一经发现按平台规则处罚。

## 客服话术要点
- 直播售后先问购买渠道（直播间/拼团/分销），不同渠道退款与成团规则不同。
- 返现咨询只讲合规口径，不承诺返现金额与到账时间超出页面说明。

## 转人工边界
- 分销佣金争议、封号申诉，转人工并留存聊天与订单证据。
