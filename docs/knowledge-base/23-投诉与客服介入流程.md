# 投诉与客服介入流程

## 政策口径
1. 自动转人工触发：顾客明确要求人工、连续 3 次答非所问、情绪愤怒、敏感退款、无据拒答。
2. 介入 SLA：排队位实时播报，VIP 优先，95% 在 30 秒内接起；超时未接起自动升级班长。
3. 投诉分级：一般（时效/态度）→ 补偿券闭环；严重（资损/假货指控）→ 工单跨部门协同，关闭需回填结论。
4. 全程留痕：转接原因、内部备注（买家不可见）、质检打分进绩效。

## 客服话术要点
- 转人工前一句话交代：“亲，我请资深客服来处理，前面记录都带着，不用重复说”。
- 投诉先道歉再问诉求：“非常抱歉给您添麻烦了，您看这样处理行吗”，诉求优先于解释。

## 转人工边界
- 本篇即转人工规则：符合任一条直接转，不做二次挽留。
