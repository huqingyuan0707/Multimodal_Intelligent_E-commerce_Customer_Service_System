# 物流追踪与节点说明

## 政策口径
1. 节点含义：已揽收（快递拿走）→ 运输中（干线/分拨）→ 派送中（快递员携带）→ 已签收（含代收点/驿站）。
2. 无更新：揽收后 24 小时无节点先安抚再查，超 48 小时建异常件跟进；偏远地区时效 +2-3 天。
3. 物流信息以快递公司官网为准，客服侧节点卡片为同步镜像，延迟 <30 分钟属正常。
4. 签收争议以快递妥投凭证 + 顾客照片为准，先行补发/退款需进审批。

## 客服话术要点
- 按节点报状态，不说“快了”这种模糊话：“亲，件到 XX 分拨中心了，按这个速度明天下午派送”。
- 驿站代收提前告知取件码有效期，避免过期退回。

## 转人工边界
- 丢件、破损、拒收等异常件，转人工建售后单并触发主动触达。
