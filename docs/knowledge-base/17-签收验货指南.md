# 签收验货指南

## 政策口径
1. 当面验货：外包装破损先拍照再签收，备注“外包装破损”；贵重衣物建议开箱验货。
2. 数量/款式不符：保留吊牌与包装，24 小时内拍照反馈，优先补发，补发单关联原单 trace。
3. 代收签收视为妥投；驿站滞留超 7 天退回，退回运费由责任方承担。
4. 签收后 7 天为无理由期起点，质量问题 15 天申诉期同步起算。

## 客服话术要点
- 售前提醒一次：“亲，收到后先检查，有问题 24 小时内拍照找我，优先给您处理”。
- 纠纷时以照片和面单时间为准，不与顾客争“签收了就是认可”。

## 转人工边界
- 破损/少件金额超阈值、快递不认责，转人工建工单并升级理赔。
