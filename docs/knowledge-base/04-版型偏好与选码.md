# 版型偏好与选码（修身/常规/宽松）

## 政策口径
1. 修身版：贴合身体曲线，胸围余量约 4-6cm；两码之间选大一码，久坐办公人群再大半码。
2. 常规版：胸围余量约 8-10cm，按平时穿码选即可，为默认推荐。
3. 宽松/Oversize：胸围余量 12cm 以上， petite 身材选小一码避免“偷穿大人衣服”既视感。
4. 有弹面料（氨纶 ≥5%）可按小一码推荐；无弹面料（纯棉/亚麻）按大一码推荐。

## 客服话术要点
- 必问一句：“亲平时喜欢穿得合身一点还是宽松一点？”再结合版型给码。
- 用余量解释原因，而不是只丢一个码：“这款是修身版，余量小，建议大一码穿着更舒服”。

## 转人工边界
- 顾客对版型描述自相矛盾（如又要修身又要能套厚毛衣），转人工结合实拍图确认。
