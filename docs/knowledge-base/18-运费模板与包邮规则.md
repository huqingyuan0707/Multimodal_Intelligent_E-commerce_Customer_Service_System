# 运费模板与包邮规则

## 政策口径
1. 包邮门槛：单笔实付满 99 元包邮（偏远地区满 199 元），未满按首重 8 元 + 续重 2 元/500g。
2. 服装轻抛件按体积重计费（长×宽×高/6000），羽绒被等蓬松件以结算页运费为准。
3. 退换运费：质量问题本店承担；无理由退货首单运费险理赔，复购无险需自理。
4. 偏远地区（西藏/新疆/内蒙古部分盟市）不包邮，下单页明示，到货时效 +3 天。

## 客服话术要点
- 运费争议先看结算页明细再解释，不凭记忆报价：“亲，这单运费 8 元是首重，页面有明细”。
- 包邮门槛差几元时可建议凑单，不能私自免运费（改价需审批）。

## 转人工边界
- 运费多收、快递到付纠纷，转人工核对面单与模板后退补。
