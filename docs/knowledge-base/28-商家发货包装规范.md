# 商家发货包装规范（内部）

## 政策口径
1. 包装标准：服装折叠 + 防尘袋 + 快递袋/纸盒，易皱面料加硬纸衬；吊牌外露可扫码，禁遮挡价签。
2. 配货校验：按打单 pick，人货对拍（SKU 条码扫码出库），错发率纳入仓管绩效。
3. 面单： thermal 打印清晰，收件信息脱敏打印（中间四位星号），一单一码禁重复使用。
4. 异常拦截：质检不合格批次暂停该 SKU 发货并公告，客服话术同步切“补货中”。

## 坐席使用要点
- 买家问“为什么发得慢”，用本篇解释仓内流程，不暴露仓管个人信息与内部系统截图。
- 错发/漏发直接走补发单（关联原单 trace），不让顾客寄回后再补。

## 转人工边界
- 批量错发、系统打单故障，转仓库协同工单并升级。
