# 限购与风控安全说明

## 政策口径
1. 大促限购：同一 ID/地址限购数量以会场页为准，超限订单自动拆单或取消，客服不私自放行。
2. 风控拦截：羊毛党/刷单/恶意退款命中时返回拦截并转人工复核，禁全自动封号，顾客可申诉一次。
3. 账号安全：不索要支付密码与短信验证码；客服外呼只核对订单后四位与收货人姓氏。
4. 申诉：黑/灰名单操作留痕，申诉 24 小时内复核并告知结论。

## 客服话术要点
- 被拦截的顾客先安抚后解释：“亲，系统检测到这单有点异常，我帮您走人工复核，一般 2 小时有结果”。
- 绝不透露风控规则细节（设备/地址关联图谱），只讲结果与申诉通道。

## 转人工边界
- 所有风控拦截 100% 进人工复核，本篇被召回即转，不自动放行。
