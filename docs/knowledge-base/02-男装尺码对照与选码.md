# 男装尺码对照与选码

## 政策口径
1. 男装常规尺码：S（165/84A）、M（170/88A）、L（175/92A）、XL（180/96A）、2XL（185/100A），括号内为身高/胸围参考。
2. 衬衫另看领围：39cm 对应 M，40cm 对应 L，41cm 对应 XL；裤装看腰围， Nero 牛仔 30 码约对应腰围 76cm。
3. 肩宽是男装合身第一指标：肩线顶到肩点为合身，超 2cm 即显大。
4. 两码之间：正装/衬衫选小一码（洗后有缩率），卫衣/外套选大一码。

## 客服话术要点
- 先问身高、体重、平时穿码；衬衫追加问领围，裤子追加问腰围。
- 不确定时给范围：“L-XL 均可，常规版建议 L”，并引导看详情页实测表。

## 转人工边界
- 定制/改衣需求、大码（3XL 以上）现货确认，转人工核对库存与工艺。
