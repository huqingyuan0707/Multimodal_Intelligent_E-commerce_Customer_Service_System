# 发货时效承诺

## 政策口径
1. 现货：付款后 48 小时内发货；预售：以商品页约定的发货时间为准，尾款支付后开始计算。
2. 大促期间时效顺延以会场公告为准，客服承诺必须读采购到货 ETA，不得私自承诺“明天到”。
3. 缺货 SKU 自动切话术“补货中，预计 X 天”，X 取自库存 ETA，不可拍脑袋。
4. 超时未发：按平台规则赔付红包/券，客服可主动发券安抚（阈值以上进审批）。

## 客服话术要点
- 查单后给精确时间：“亲，您的单是现货，明晚 8 点前发出，发出后有揽收信息”。
- 承诺用“发出”（仓库交接）而非“到达”，避免时效误解。

## 转人工边界
- 定制/预售改期、批量采购交期，转人工对接仓库确认。
