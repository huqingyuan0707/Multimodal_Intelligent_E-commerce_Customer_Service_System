# 发票开具说明

## 政策口径
1. 普票：下单时填写抬头税号，确认收货后 3 个工作日内开具电子票，发送至预留邮箱/短信。
2. 专票：需对公转账订单，提供开票资料（名称/税号/地址电话/开户行账号），5 个工作日内开具。
3. 退款订单：全额退款后已开票据作废重开；部分退款按实付重开，差额 3 个工作日处理。
4. 抬头税号由顾客提供，客服不修改税号，只核对位数与格式后提交财务。

## 客服话术要点
- 先问发票类型（普票/专票）再问资料，一次收齐避免反复。
- 给明确时效：“亲，资料齐了，普票 3 个工作日内发到您邮箱”。

## 转人工边界
- 专票资料不全、跨月红冲、税号争议，转财务对接。
