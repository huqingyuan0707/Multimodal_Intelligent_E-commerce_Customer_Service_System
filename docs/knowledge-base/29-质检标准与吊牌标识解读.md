# 质检标准与吊牌标识解读（内部）

## 政策口径
1. 出厂质检：执行 GB 18401（B 类直接接触皮肤）/ GB 31701（童装 A 类），甲醛/pH/色牢度见检测报告编号，坐席可向顾客出示报告编号，报告原件不外发。
2. 吊牌必备项：品名/成分/执行标准/安全类别/洗涤符号/产地/经销商，缺项即下架整改。
3. 洗涤符号：桶形=水洗（数字为水温上限）、方块=晾干、三角形=可否漂白、熨斗=熨烫温度、圆圈=干洗，叉号即禁止。
4. 到货质检：采购到货抽检比例 10%，不合格触发客服拦截（暂停该批次销售并公告）+ 退供流程。

## 坐席使用要点
- 顾客问“掉色/缩水正常吗”，先查成分与洗涤符号，再引用面料洗护篇作答，不脱离标识承诺。
- 成分争议以吊牌 + 检测报告为准，口头承诺无效。

## 转人工边界
- 吊牌与实物不符、疑似三无/假冒，转质检工单并冻结该 SKU 销售。
