# 评价晒单与邀评规则

## 政策口径
1. 邀评：签收 N 天后自动邀评一次，不重复打扰；中差评 2 小时响应 SLA，超时升级。
2. 差评处理：一评一策——先回复致歉，再建工单（质检/仓库/客服），处理完回访，结论打标反哺选品。
3. 合规红线：禁“好评返现才发货”“不给好评不退款”等诱导胁迫；返现仅限晒图追评且金额在页面明示范围。
4. 晒单奖励：带图评价 + 追评可领小额券，审核通过后发放，恶意刷评取消资格。

## 客服话术要点
- 差评回复模板：“非常抱歉（具体问题）+ 已安排（措施）+ 预计（时间）+ 专属跟进”，不辩解、不推诿。
- 邀评话术只问体验，不索要好评：“亲，衣服还合身吗，欢迎分享穿搭哦”。

## 转人工边界
- 恶意差评勒索、平台处罚申诉，转人工并留存证据链。
