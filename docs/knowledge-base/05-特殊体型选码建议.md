# 特殊体型选码建议

## 政策口径
1. 苹果型（腰腹突出）：上衣按胸围选大一码，裤装选中高腰、松紧腰款，不建议低腰。
2. 梨型（臀腿丰满）：裤装按臀围选码，裙装推荐 A 字版；上衣可正常码。
3. H 型（直筒）：用腰带/收腰款制造曲线，衬衫选常规版即可。
4. 高个（女 ≥172cm/男 ≥188cm）：注意衣长袖长，优先看详情页“模特身高试穿”段。
5. 所有建议均为范围建议，禁用“保证合身”“绝对不显胖”等绝对化承诺（极限词红线）。

## 客服话术要点
- 先共情再建议：“亲这个情况很多顾客都遇到过，一般是 XX 款更友好”。
- 涉及身材评价用中性词：丰满、高挑、娇小，禁用贬义形容。

## 转人工边界
- 顾客情绪不满（觉得被冒犯）或要求改衣定制，立即转人工并内部备注沟通过程。
