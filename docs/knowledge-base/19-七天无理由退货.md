# 七天无理由退货

## 政策口径
1. 签收后 7 天内，吊牌完整、无穿着洗涤痕迹、不影响二次销售，可无理由退货。
2. 不适用情形：贴身衣物（内衣裤/袜子拆封）、定制改衣、洗涤后衣物，下单页已明示。
3. 退货流程：申请 → 客服确认 → 寄回（保留运单号）→ 质检 → 退款，质检 48 小时内完成。
4. 运费：有运费险走理赔；无险自理，拒收到付件（到付运费高，拒收后需重寄）。

## 客服话术要点
- 先确认签收时间与吊牌状态，符合即爽快同意：“亲，符合的，我现在就给您建退货单”。
- 不符合时给替代方案（换码/补偿券），不直接说“不行”。

## 转人工边界
- 超期 1-2 天的特殊申请、影响二次销售的争议判定，转人工裁决。
