# 纯棉T恤洗护指南

## 政策口径
1. 水温 30℃ 以下机洗，反面洗涤；深浅色分开，首次下水轻微掉色属正常。
2. 禁用漂白剂，不可烘干暴晒，阴凉处晾干；晾晒时抖平、衣架从下摆套入防领口变形。
3. 重磅（≥220g）纯棉首次缩率约 3%，选码时已预留余量不作为质量问题。
4. 印花款：印花面不熨烫，翻面轻柔洗，印花细小裂纹属穿着摩擦正常现象。

## 客服话术要点
- 售后“变形/掉色”先问洗涤方式，再对照本篇逐条排查，多数可给出正确洗法闭环。
- 话术：“亲，纯棉都会有一点缩水和掉色，按这个方法洗可以最大程度保持版型哦”。

## 转人工边界
- 大面积褪色、印花整块脱落（疑似工艺问题），转人工并请顾客提供洗后照片。
