# 瑕疵定级与处理方案

## 政策口径
1. 瑕疵类别：污渍 / 破洞 / 脱线 / 色差 / 开线 / 尺寸不符 / 吊牌异常 / 无瑕疵。
2. 定级标准：轻微（线头/小污渍可清理）→ 补偿券；明显（破洞/开线 >1cm/洗不掉的污渍）→ 换货或退款；严重（大面积破损/错版）→ 退款 + 补偿。
3. VLM 检测置信度 ≥0.6 直接定级拼入回复；<0.6 或顾客坚持有瑕疵而检测为无瑕疵时，转人工复核，不硬答。
4. 证据留存：瑕疵图打码人脸后存对象存储，售后单关联会话 trace_id。

## 客服话术要点
- 检测卡+政策引用一起给：“检测为脱线约 2cm（0.82），按售后政策给您换货，明天发出”。
- 顾客坚持时先认可感受再升级：“我理解您的心情，这就请质检同事复核”。

## 转人工边界
- 低置信、定级争议、同一订单第三次售后，自动转人工。
