# 羽绒羊毛洗护指南

## 政策口径
1. 羽绒服：建议干洗；可机洗时用柔和档 + 中性洗涤剂，忌拧绞，晾干后拍打恢复蓬松；小面积污渍优先局部擦洗。
2. 羊毛/羊绒：干洗优先；手洗用 30℃ 以下冷水 + 羊毛专用液，轻压忌搓，卷毛巾吸水后平铺晾干。
3. 跑绒：少量钻绒（每天数根）属正常，切忌从面料往外拽绒，应从内里把绒拉回；大面积跑绒按瑕疵流程处理。
4. 起球：羊毛穿着摩擦起球正常，赠送/建议使用毛球修剪器，不属于质量问题。

## 客服话术要点
- 先安抚：“亲，钻绒和起球是这类面料的共性，处理方法很简单”，再给步骤。
- 跑绒判断标准量化给顾客：每天数根正常、一抖一把转售后。

## 转人工边界
- 大面积跑绒、洗后严重缩绒变形，转人工并关联瑕疵定级篇走退换。
