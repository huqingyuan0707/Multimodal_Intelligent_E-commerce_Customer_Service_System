# 数据模型与存储设计（PG + 向量 + Redis + 对象存储）

> 对齐后端风格：配置进 `app/config.py::Settings`，向量/关键词走适配层，业务代码不直连具体库。

## 1. ER 总览

```
tenants(租户/订阅/配额) ─┬─ users(Token用户名/角色)
                         ├─ sessions/threads(会话) ── messages(多模态+引用+trace)
                         ├─ kb_docs(主题/版本/生效期) ── kb_chunks(向量ID/关键词)
                         ├─ tasks(异步/检查点) ── approvals(敏感动作)
                         ├─ tool_calls(审计) ── feedbacks(点赞踩/纠错)
                         ├─ products ── skus ─┬─ inventory(仓×SKU/预占/锁定) ── stock_moves(流水)
                         │                    └─ sales_orders(平台镜像/trace) ── finance_bills(日结)
                         ├─ suppliers ── purchase_orders(审批/质检/入库)
                         ├─ promos ── coupon_grants(幂等/预算) + members(等级/积分)
                         ├─ logistics_orders(面单/异常) + reviews(差评→工单)
                         ├─ tickets(协同/SLA) + risk_events(复核) + notify_logs(到达率)
                         ├─ warehouses(仓管按仓过滤)
                         ├─ screen_daily(经营快照宽表)
                         ├─ api_keys(密钥摘要/掩码) / slo_rules(阈值口径)
                         ├─ message_templates(模板+累计到达) / shifts(排班)
                         └─ audit_logs(不可改) / cost_records(归因)
```

所有业务表必带 `tenant_id`，读写一律 `governance.access_context()` 推导，禁止用请求体 tenant 做判断。

## 2. PostgreSQL DDL（最小闭环，可直接 Alembic 落库）

```sql
create table tenants(id uuid primary key, name text not null, plan text default 'trial',
  quota_tokens bigint default 1000000, created_at timestamptz default now());
create table users(id uuid primary key, tenant_id uuid references tenants(id),
  username text not null, role text not null, created_at timestamptz default now(),
  unique(tenant_id, username));
create table sessions(id uuid primary key, tenant_id uuid not null, username text not null,
  title text default '新会话', security_level text default 'internal',
  summary text default '', -- 长会话规则摘要（超 HISTORY_ROUNDS 轮刷新，进 LLM 替代逐条历史）
  handoff_status text default 'none', -- 坐席流转 none→pending→handling→resolved（FR-7，索引）
  assignee text default '', handoff_reason text default '',
  handoff_skill text default 'general', -- 挂起时按规则表路由的技能组（general/refund/complaint/aftersale）：
  -- 队列筛选、认领门禁（坐席 roles 的 cs:<组> 令牌，general 人人可接、admin 全组）、
  -- 智能分配（技能匹配+在手最少+未达 HANDOFF_LOAD_LIMIT）都读它；口径唯一出处 handoff_rules
  resolution text default '',
  created_at timestamptz default now(), updated_at timestamptz default now());
create index on sessions(tenant_id, username, updated_at desc);
-- 上下文口径（FR-1.4）：窗口 SESSION_HISTORY_ROUNDS（20 轮）+ 预算 SESSION_TOKEN_BUDGET
-- （8000 token，中文 1.5 字/token）+ PII 正则清洗；附件转写成 [图：破洞 0.85] 行进历史。
create table messages(id uuid primary key, session_id uuid not null references sessions(id) on delete cascade,
  role text not null, modality text default 'text', content text,
  attachments jsonb default '[]', citations jsonb default '[]',
  guard jsonb default '{}', faithfulness float, trace_id text, client_msg_id text default '',
  created_at timestamptz default now());
create index on messages(session_id, created_at);
create index on messages(client_msg_id); -- 流式幂等键：同（会话，键）重调只落一行，重放不再调模型
create table user_preferences(id uuid primary key, tenant_id uuid not null, username text not null,
  key text not null, value text not null, source text default 'explicit',
  created_at timestamptz default now(), updated_at timestamptz default now(),
  unique(tenant_id, username, key));
-- 长期偏好（FR-4）：用户级键值记忆，仅显式"记住"授权落库（PII 永不进），迁移 e5f6a7b8c9d0；
-- 一键遗忘按户清（DELETE /auth/me/memory），会话消息原文不动
create table kb_docs(id uuid primary key, tenant_id uuid not null, title text not null, content text not null,
  topic text default '', status text default 'published', submitted_by text default '', published_by text default '',
  channels text[] default '{all}', security_level text default 'internal',
  valid_from timestamptz, valid_to timestamptz, sha256 text, version int default 1,
  created_at timestamptz default now(), unique(tenant_id, sha256));
-- 生命周期（FR-13.2）：draft→review→published→archived；检索 SQL 只收 published；迁移 f2a3b4c5d6e7（存量默认 published）
create table kb_doc_versions(id uuid primary key, tenant_id uuid not null,
  doc_id uuid references kb_docs(id) on delete cascade, version int default 1,
  title text default '', content text default '', sha256 text default '',
  actor text default '', action text default 'create', created_at timestamptz default now());
-- 版本历史只追加（create/update/publish/rollback）；回滚=旧内容新版本；messages.citations 供引用统计聚合
create table kb_chunks(id uuid primary key, doc_id uuid references kb_docs(id) on delete cascade,
  ord int, content text, vector_id text, updated_at timestamptz default now());
create table tasks(id uuid primary key, tenant_id uuid not null, username text not null,
  type text, status text default 'pending', progress float default 0,
  input jsonb, output jsonb, error jsonb, checkpoint jsonb,
  created_at timestamptz default now(), updated_at timestamptz default now());
create table approvals(id uuid primary key, tenant_id uuid not null, session_id uuid,
  action text, args jsonb, status text default 'pending', approver text, reason text,
  created_at timestamptz default now(), decided_at timestamptz);
create table tool_calls(id uuid primary key, trace_id text, tenant_id uuid, username text,
  name text, args jsonb, result jsonb, latency_ms int, created_at timestamptz default now());
create table feedbacks(id uuid primary key, message_id uuid references messages(id),
  vote text, comment text, created_at timestamptz default now());
create table audit_logs(id uuid primary key, tenant_id uuid, actor text, action text,
  target text, detail jsonb, created_at timestamptz default now());
create table cost_records(id uuid primary key, tenant_id uuid, session_id uuid, model text,
  prompt_tokens int, completion_tokens int, cost_cents int, pricing_source text default 'estimate',
  created_at timestamptz default now());
-- pricing_source：usage=上游 tokens 实数，estimate=估算；归因误差度量=estimate 费用占比（越低越准），迁移 d9e8f7a6b5c4。
create table prompt_versions(id uuid primary key, tenant_id uuid not null, version text not null,
  desc text default '', content text default '', variables jsonb default '[]', gray int default 0,
  status text default 'draft', created_by text default '',
  created_at timestamptz default now(), updated_at timestamptz default now(), unique(tenant_id, version));
-- Prompt 状态机 draft→gray→online（全量恒 gray=100），发布/回滚前现存 online/gray 转 archived（单线上口径）；
-- 全量发布需最近 eval accept_ok（Studio 服务层硬拦，前端红条同源）；content 变量 {{var}} 建版时自动提取。
create table eval_runs(id uuid primary key, tenant_id uuid not null, name text default 'default-200',
  limit int default 50, status text default 'pending', score jsonb default '{}', elapsed_ms int default 0,
  error text default '', created_by text default '',
  created_at timestamptz default now(), updated_at timestamptz default now());
-- 评测 run：pending→running→done/failed；score 与 scripts/eval_golden 同口径 + 双档 verdict
-- （ratchet_ok/accept_ok）+ guard_dist/misses；pass=ratchet_ok（与 CI RESULT 出口一致）。
-- 审计只追加不改；PII 不存明文手机地址全文；留痕 ≥6 个月；遗忘走 DELETE sessions 级联 + 向量删除
-- + 记忆键删除（sess 线程快照随会话删）+ user_preferences 按户清（DELETE /auth/me/memory）。

-- ---- 管理后台扩展（FR-8/FR-12.2/FR-12.4，迁移 b8c9d0e1f2a3 + c9d0e1f2a3b4）----
alter table users add column status text not null default 'active';  -- active 正常 / frozen 离职冻结（另建 index(status)）
-- users.status：冻结即拒登（auth_service.authenticate 验密后校验，顺序不可前置——否则成账号探测器），
-- 但**行保留**：会话、绩效、审计仍需回溯到人，与「删账号」是两件事。
create table api_keys(id uuid primary key, tenant_id uuid not null, name text not null,
  prefix text default '', masked text default '', key_hash text not null, scopes text default '',
  status text default 'active', last_used_at timestamptz, expires_at timestamptz, rotated_at timestamptz,
  created_at timestamptz default now(), unique(tenant_id, name), unique(key_hash));
-- 密钥只存 sha256 摘要，明文仅在创建/轮换响应里回一次；masked 是列表唯一可见口径，
-- 任何读取路径都不得回明文或摘要（出参结构上就不含这两个字段）。轮换＝覆盖摘要，旧口令立即失效。
create table slo_rules(id uuid primary key, tenant_id uuid not null, metric text not null,
  operator text default 'gte', threshold double precision default 0, window text default 'realtime',
  enabled boolean default true, note text default '', created_at timestamptz default now(),
  updated_at timestamptz default now(), unique(tenant_id, metric));
-- SLO 只存**阈值口径**，不落「当前是否超标」的冗余状态（避免两处事实源）：实时值每次现取
-- core/observability.snapshot()，且该值是**进程级聚合（含全部租户）**，响应以 metric_scope/scope_note 标注。
-- window 现仅 realtime；today/week 需 JSONL 历史报表（E 步未完成）故不入白名单，避免假能力。
create table message_templates(id uuid primary key, tenant_id uuid not null, name text not null,
  channel text default 'sms', content text default '', status text default 'draft',
  reach_total int default 0, reach_failed int default 0,
  created_at timestamptz default now(), updated_at timestamptz default now(), unique(tenant_id, name));
-- reach_total/reach_failed 为**累计**口径（无时间窗，发送明细表待网关接入时补）；
-- 频控计数不落库，走 core/cache 的 rl:{tenant}:notify:{user_ref}（与对话限流同一适配层）。
create table shifts(id uuid primary key, tenant_id uuid not null, username text not null,
  work_date text not null, start_time text default '09:00', end_time text default '18:00',
  skill text default 'general', note text default '', created_at timestamptz default now());
create index on shifts(tenant_id, work_date);
-- work_date 存 'YYYY-MM-DD' 文本：字典序即时间序，SQLite/PG 行为一致，免时区歧义；
-- skill 取值与 handoff_rules.skill_groups() 同源（排班与队列路由必须同一套组名，否则排了班接不到单）。

## 4. Redis 键规范

| 用途 | Key | TTL |
|---|---|---|
| 短期记忆 | `sess:{tenant}:{username}:{thread}`（消息窗口+摘要） | 24h 滑动 |
| 用户近况 | `mem:{tenant}:{username}`（跨会话事实：身高/体重/版型/预算/尺码，PII 不进） | 24h 滑动 |
| 限流 | `rl:{tenant}:{username}:{api}` | 分钟窗 |
| 幂等 | `idem:{key}` → 结果 | 24h |
| 热点缓存 | `rag:{hash(query+tenant+level)}` / `model:{hash}` | 10min-1h |
| 队列 | `q:tasks` + `q:reindex`（Celery/ARQ） | 持久化 |
| 库存预占 | `stock:{tenant}:{warehouse}:{sku}`（原子扣减，DB 双写） | 随订单生命周期 |
| 大屏缓存 | `screen:{tenant}:{range}`（日快照聚合） | 1min |
| 发券预算 | `promo:{tenant}:{promo_id}`（原子扣减防超发） | 活动有效期 |
| 消息频控 | `notify:{tenant}:{user}:{day}`（营销 1 条/人/天） | 24h |

记忆读写键必须是 `(tenant, Token用户名, thread)` 同一口径，与鉴权同源。

## 5. 对象存储

` s3://app/{tenant}/%Y/%m/{session_id}/{uuid}.jpg|mp3 `，元数据进 `attachments`。流程：上传 → NSFW/人脸 → 打码后存 → 瑕疵检测。单图 ≤10M，总 ≤9 张；语音 ≤60s。前端 `FormData` 上传，不手设 `Content-Type`。

**可观测事件留痕（E 步，`core/observability.py`）：** 关键链路事件（`chat` / `llm` / `agent.tool` / `agent.run` / `agent.orchestrate` / `handoff` / `handoff.claim` / `rag.*` 步骤）经 `record()` 双出口——①进程内计数器/滑窗（`GET /workbench/metrics` 即时聚合 30s 接起率、LLM/工具成功率，重启清零）；②守护线程批量落 JSONL `data/observability/events-YYYYMMDD.jsonl`（`Settings.OBSERVABILITY_DIR`，每行 `{"ts","event",...语义字段}`，重启不丢历史）。红线：`record()` 绝不抛错、绝不阻塞业务；接 Prometheus/Langfuse 网关后只替换本模块落盘出口，事件名与字段口径不变。

## 6. 迁移与种子
Alembic 版本化，先加字段后发代码再删旧字段，向前兼容；发布前迁移 Job 先行；每日全量 + WAL，定期恢复演练。种子：默认租户 + 管理员 + 7 大服装主题知识 + 敏感词库。

**账号种子（登录链路实现口径，对齐 `backend/app/db/seed.py`）：**

- 唯一键 `unique(tenant, username)`（开发态 SQLite 由 `app/db/models.py` 表达），密码只存 PBKDF2 哈希（`pwd_hash`），禁止明文/可逆加密。
- 灌种子入口两处：后端 `lifespan`（由 `SEED_ON_START` 开关）与 `scripts/init_db.py`（不启动服务时兜底），**均幂等**——已存在不覆盖，避免重启冲掉改过的密码。
- 账号参数全走 `Settings`：`SEED_TENANT / SEED_USERNAME / SEED_PASSWORD / SEED_ROLES`（本地演示默认值见 `backend/.env.example`，本机专用），`.env` 可覆盖，**禁止硬编码**；生产必须 `ENV=prod` + `SEED_ON_START/B2B_SEED_DEMO/KB_SEED_DEMO` 全关（缺一即启动报错）并轮换 `JWT_SECRET`（≥32 字节），首个管理员走 `backend/scripts/create_admin.py` 创建。
- 登录态：Token 有效期 `ACCESS_TOKEN_EXPIRE_SECONDS`、算法 `JWT_ALGORITHM` 进 `Settings`；JWT 无状态，服务端不落会话表，登出仅确认身份，Token 只存前端 `sessionStorage.reai_token`。
- 口令哈希：`PASSWORD_HASH_ITERATIONS`（默认 100000）/ `PASSWORD_SALT_BYTES`（默认 16）进 `Settings`，落库格式 `salt$hex` 不变；**改迭代次数须同步重刷存量密码**，否则一律验密失败。
- 角色文本：分隔符走 `ROLES_SEPARATOR`，解析统一用 `app/core/security.py::split_roles()`（`"cs,kb" -> ["cs","kb"]`），种子写入与认证读取同源。
- 角色/权限即 `roles` 文本列，`require_perm()` 直接比对；`"*"` 表示通配（当前无内置超管账号，种子默认 `cs,kb`）。
