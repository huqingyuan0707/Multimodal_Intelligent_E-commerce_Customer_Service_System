# 数据模型与存储设计（PG + 向量 + Redis + 对象存储）

> 对齐后端风格：配置进 `app/config.py::Settings`，向量/关键词走适配层，业务代码不直连具体库。

## 1. ER 总览

```
tenants(租户/订阅/配额) ─┬─ users(Token用户名/角色)
                         ├─ sessions/threads(会话) ── messages(多模态+引用+trace)
                         ├─ kb_docs(主题/版本/生效期) ── kb_chunks(向量ID/关键词)
                         ├─ tasks(异步/检查点) ── approvals(敏感动作)
                         ├─ tool_calls(审计) ── feedbacks(点赞踩/纠错)
                         ├─ products ── skus ─┬─ inventory(仓×SKU/预占/锁定) ── stock_moves(流水)
                         │                    └─ sales_orders(平台镜像/trace) ── finance_bills(日结)
                         ├─ suppliers ── purchase_orders(审批/质检/入库)
                         ├─ promos ── coupon_grants(幂等/预算) + members(等级/积分)
                         ├─ logistics_orders(面单/异常) + reviews(差评→工单)
                         ├─ tickets(协同/SLA) + risk_events(复核) + notify_logs(到达率)
                         ├─ warehouses(仓管按仓过滤)
                         ├─ screen_daily(经营快照宽表)
                         └─ audit_logs(不可改) / cost_records(归因)
```

所有业务表必带 `tenant_id`，读写一律 `governance.access_context()` 推导，禁止用请求体 tenant 做判断。

## 2. PostgreSQL DDL（最小闭环，可直接 Alembic 落库）

```sql
create table tenants(id uuid primary key, name text not null, plan text default 'trial',
  quota_tokens bigint default 1000000, created_at timestamptz default now());
create table users(id uuid primary key, tenant_id uuid references tenants(id),
  username text not null, role text not null, created_at timestamptz default now(),
  unique(tenant_id, username));
create table sessions(id uuid primary key, tenant_id uuid not null, username text not null,
  title text default '新会话', security_level text default 'internal',
  summary text default '', -- 长会话规则摘要（超 HISTORY_ROUNDS 轮刷新，进 LLM 替代逐条历史）
  created_at timestamptz default now(), updated_at timestamptz default now());
create index on sessions(tenant_id, username, updated_at desc);
-- 上下文口径（FR-1.4）：窗口 SESSION_HISTORY_ROUNDS（20 轮）+ 预算 SESSION_TOKEN_BUDGET
-- （8000 token，中文 1.5 字/token）+ PII 正则清洗；附件转写成 [图：破洞 0.85] 行进历史。
create table messages(id uuid primary key, session_id uuid not null references sessions(id) on delete cascade,
  role text not null, modality text default 'text', content text,
  attachments jsonb default '[]', citations jsonb default '[]',
  guard jsonb default '{}', faithfulness float, trace_id text, client_msg_id text default '',
  created_at timestamptz default now());
create index on messages(session_id, created_at);
create index on messages(client_msg_id); -- 流式幂等键：同（会话，键）重调只落一行，重放不再调模型
create table kb_docs(id uuid primary key, tenant_id uuid not null, title text not null, content text not null,
  channels text[] default '{all}', security_level text default 'internal',
  valid_from timestamptz, valid_to timestamptz, sha256 text, version int default 1,
  created_at timestamptz default now(), unique(tenant_id, sha256));
create table kb_chunks(id uuid primary key, doc_id uuid references kb_docs(id) on delete cascade,
  ord int, content text, vector_id text, updated_at timestamptz default now());
create table tasks(id uuid primary key, tenant_id uuid not null, username text not null,
  type text, status text default 'pending', progress float default 0,
  input jsonb, output jsonb, error jsonb, checkpoint jsonb,
  created_at timestamptz default now(), updated_at timestamptz default now());
create table approvals(id uuid primary key, tenant_id uuid not null, session_id uuid,
  action text, args jsonb, status text default 'pending', approver text, reason text,
  created_at timestamptz default now(), decided_at timestamptz);
create table tool_calls(id uuid primary key, trace_id text, tenant_id uuid, username text,
  name text, args jsonb, result jsonb, latency_ms int, created_at timestamptz default now());
create table feedbacks(id uuid primary key, message_id uuid references messages(id),
  vote text, comment text, created_at timestamptz default now());
create table audit_logs(id uuid primary key, tenant_id uuid, actor text, action text,
  target text, detail jsonb, created_at timestamptz default now());
create table cost_records(id uuid primary key, tenant_id uuid, session_id uuid, model text,
  prompt_tokens int, completion_tokens int, cost_cents int, created_at timestamptz default now());
-- 审计只追加不改；PII 不存明文手机地址全文；留痕 ≥6 个月；遗忘走 DELETE sessions 级联 + 向量删除。

## 2.1 B端进销存 DDL（续 §2，同 tenant 隔离 + 审计，见 FRDv2 附录 E）

```sql
create table products(id uuid primary key, tenant_id uuid not null, spu_no text not null, name text not null,
  images jsonb default '[]', attrs jsonb default '{}', status text default 'draft', created_at timestamptz default now(), unique(tenant_id, spu_no));
create table skus(id uuid primary key, product_id uuid references products(id) on delete cascade,
  color text, size text, barcode text, list_price int, sale_price int, status text default 'on', unique(product_id, color, size));
create table warehouses(id uuid primary key, tenant_id uuid not null, name text not null, created_at timestamptz default now());
create table inventory(warehouse_id uuid references warehouses(id), sku_id uuid references skus(id),
  qty int default 0, reserved int default 0, locked int default 0, warn_line int default 10,
  primary key(warehouse_id, sku_id));
create table stock_moves(id uuid primary key, tenant_id uuid not null, warehouse_id uuid, sku_id uuid,
  kind text, delta int, order_ref text, reason text, actor text, created_at timestamptz default now());
create index on stock_moves(tenant_id, sku_id, created_at);
create table suppliers(id uuid primary key, tenant_id uuid not null, name text, pay_terms text, pass_rate float, created_at timestamptz default now());
create table purchase_orders(id uuid primary key, tenant_id uuid not null, supplier_id uuid references suppliers(id),
  items jsonb default '[]', status text default 'draft', eta date, created_at timestamptz default now());
create table sales_orders(id uuid primary key, tenant_id uuid not null, platform text, outer_id text not null,
  items jsonb default '[]', total int, status text default 'pending_pay', trace_id text, created_at timestamptz default now(), unique(tenant_id, platform, outer_id));
create table finance_bills(id uuid primary key, tenant_id uuid not null, biz_date date not null,
  receivable int, received int, refund int, fee int, diff int, settled_by text, created_at timestamptz default now());
create table screen_daily(tenant_id uuid not null, biz_date date not null, metrics jsonb default '{}',
  primary key(tenant_id, biz_date));
-- 可用 = qty - reserved - locked，并发扣减走 Redis 原子 + DB 双写；售后单经 trace_id 关联会话；单据全审计。
```

## 3. 向量 / 关键词适配层

```python
"""向量存储适配（对齐 RAG 规范，业务不直连 Chroma/pgvector/Milvus）"""
class VectorStore:
    async def upsert(self, ids: list[str], vecs: list[list[float]], metas: list[dict]) -> None: ...
    async def search(self, vec: list[float], top_k: int, flt: dict) -> list[dict]: ...
    def status(self) -> dict: ...  # 可用性 governance/status 可见，不可用自动回退关键词
```

- 全部可调进 `Settings`：`EMB_MODEL/BGE_RERANKER/HF_ENDPOINT/TOP_K/THRESHOLD/HOT_FIELDS`，禁止硬编码模型名/阈值/URL。
- 热更走 `_HOT_FIELDS` + 落盘；模型下载前 `os.environ.setdefault("HF_ENDPOINT", settings.HF_ENDPOINT)`。
- 惰性单例双检锁（如 `rag.py::_embed_model + _meta_lock`），阻塞加载走 `to_thread`。

## 4. Redis 键规范

| 用途 | Key | TTL |
|---|---|---|
| 短期记忆 | `sess:{tenant}:{username}:{thread}`（消息窗口+摘要） | 24h 滑动 |
| 限流 | `rl:{tenant}:{username}:{api}` | 分钟窗 |
| 幂等 | `idem:{key}` → 结果 | 24h |
| 热点缓存 | `rag:{hash(query+tenant+level)}` / `model:{hash}` | 10min-1h |
| 队列 | `q:tasks` + `q:reindex`（Celery/ARQ） | 持久化 |
| 库存预占 | `stock:{tenant}:{warehouse}:{sku}`（原子扣减，DB 双写） | 随订单生命周期 |
| 大屏缓存 | `screen:{tenant}:{range}`（日快照聚合） | 1min |
| 发券预算 | `promo:{tenant}:{promo_id}`（原子扣减防超发） | 活动有效期 |
| 消息频控 | `notify:{tenant}:{user}:{day}`（营销 1 条/人/天） | 24h |

记忆读写键必须是 `(tenant, Token用户名, thread)` 同一口径，与鉴权同源。

## 5. 对象存储

` s3://app/{tenant}/%Y/%m/{session_id}/{uuid}.jpg|mp3 `，元数据进 `attachments`。流程：上传 → NSFW/人脸 → 打码后存 → 瑕疵检测。单图 ≤10M，总 ≤9 张；语音 ≤60s。前端 `FormData` 上传，不手设 `Content-Type`。

## 6. 迁移与种子
Alembic 版本化，先加字段后发代码再删旧字段，向前兼容；发布前迁移 Job 先行；每日全量 + WAL，定期恢复演练。种子：默认租户 + 管理员 + 7 大服装主题知识 + 敏感词库。

**账号种子（登录链路实现口径，对齐 `backend/app/db/seed.py`）：**

- 唯一键 `unique(tenant, username)`（开发态 SQLite 由 `app/db/models.py` 表达），密码只存 PBKDF2 哈希（`pwd_hash`），禁止明文/可逆加密。
- 灌种子入口两处：后端 `lifespan`（由 `SEED_ON_START` 开关）与 `scripts/init_db.py`（不启动服务时兜底），**均幂等**——已存在不覆盖，避免重启冲掉改过的密码。
- 账号参数全走 `Settings`：`SEED_TENANT / SEED_USERNAME / SEED_PASSWORD / SEED_ROLES`（开发默认 `demo-tenant / admin / admin123 / cs,kb`），`.env` 可覆盖，**禁止硬编码**；生产必须 `SEED_ON_START=false` 并轮换 `JWT_SECRET`（≥32 字节）。
- 登录态：Token 有效期 `ACCESS_TOKEN_EXPIRE_SECONDS`、算法 `JWT_ALGORITHM` 进 `Settings`；JWT 无状态，服务端不落会话表，登出仅确认身份，Token 只存前端 `sessionStorage.reai_token`。
- 口令哈希：`PASSWORD_HASH_ITERATIONS`（默认 100000）/ `PASSWORD_SALT_BYTES`（默认 16）进 `Settings`，落库格式 `salt$hex` 不变；**改迭代次数须同步重刷存量密码**，否则一律验密失败。
- 角色文本：分隔符走 `ROLES_SEPARATOR`，解析统一用 `app/core/security.py::split_roles()`（`"cs,kb" -> ["cs","kb"]`），种子写入与认证读取同源。
- 角色/权限即 `roles` 文本列，`require_perm()` 直接比对；`"*"` 表示通配（当前无内置超管账号，种子默认 `cs,kb`）。
